romledger options

Connection

The extension talks to romledger on this computer. Run romledger extension install once in a terminal, reload the extension, then check the connection.

Downloads

Downloading from Vimm's Lair needs a Chromium browser. Firefox does not offer the event it relies on.

Asks the browser for the downloads permission. It lets the Download button on a Vimm's Lair list page fetch every missing game, and moves downloads you start yourself into that folder. Add ~/Downloads/romledger to library.inboxes and each finished download is imported at once.
